## Design Context

### Users
Architects and design professionals who need a structured, precise, and professional environment for creating and managing flowcharts.

### Brand Personality
Professional, confident, and precise. The interface should feel like a high-end tool that architects would trust.

### Aesthetic Direction
"Page Architect" style: Professional, structured, and minimalist. Think architectural blueprints, clean lines, high-contrast typography, and a grid-based layout. It should avoid generic "AI" looks and focus on clarity and precision.

### Design Principles
1. **Precision & Clarity**: Every element should have a clear purpose and be aligned to a strict grid.
2. **Professional Trust**: Use a sophisticated color palette and refined typography to evoke confidence.
3. **Structured Minimalism**: Remove unnecessary noise; focus on the core task with generous whitespace.
4. **Architectural Aesthetic**: Incorporate subtle elements that nod to architectural design (e.g., fine lines, technical labels, blueprint-inspired accents).
